# Sorting Algorithm Visualizer

Real-time sorting algorithm visualization built with Python and Pygame.

## Features
- Bubble Sort visualization
- Merge Sort visualization
- Quick Sort visualization
- Real-time comparison & swap counters
- Color coding: Comparing (orange) / Sorted (purple)
- Adjustable speed 
- Reset array

## Controls
- R: Reset array
- ↑: Speed up
- ↓: Speed down
- 1: Bubble sort
- 2: Merge sort
- 3: Quick sort

## Setup
```bash
# Clone the repository
git clone https://github.com/Nayeoncho/sorting-visualizer.git
cd sorting-visualizer

# Create and activate virtual environment
python -m venv venv
venv\Scripts\activate     # Windows
source venv/bin/activate  # Mac/Linux

# Install dependencies
pip install pygame

# Run
python main.py
```
